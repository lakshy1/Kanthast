Doubts: class forum, AI help and video explainers

Doubts is a new logged-in section of the School app. A student asks the AI first. If that does not settle it, they post the doubt to their own class, where classmates or the AI can answer. Any doubt can be turned into a one-minute explainer video built from reusable 12-second scenes.

How Doubts works

Three sections on one page

SectionWhat it isWho sees it
AskPrivate AI chat. This is today's Assistant, moved here with its history, file upload and suggestions. It is the default view.Only the student
Class feedDoubts posted by classmates, with filters for subject and chapter.The student's class
MineThe student's own doubts, replies to them, and their videos.Only the student

The main flow

  1. Ask the AI.The student types a doubt in Ask and gets a private answer in seconds. A toggle switches between a hint and a full solution.
  2. Solved? Stop here.Nothing is posted. Easy questions never reach the feed.
  3. Still confused? Post to the class.The AI turns the chat into a short post with subject and chapter filled in. The student edits it and posts. This uses one of the day's posts.
  4. Similar doubts appear while typing.If classmates already asked the same thing, the student can open those answers instead of posting.
  5. Classmates answer.Anyone in the class can write an answer, or press Answer using AI to add one labelled AI answer to the thread.
  6. Make a video.A button on the doubt creates a one-minute explainer. It is attached to the thread, so the next student with the same doubt gets it at no cost.
  7. Mark the answer that helped.Only the student who asked can do this. That answer moves to the top.

Rules

  • AI answers are always labelled. One AI answer per thread. The student who pressed the button earns no helper points for it.
  • No private messages. All talk stays in class threads.
  • Names are limited. Students appear as first name, class and an avatar. No photos, surnames or school names.
  • Reactions are positive only. There is a "This helped me" button and no downvote.
  • Helper points and badges go to students whose answers help. A weekly list shows top helpers per class.
  • English help, not an error. If a student writes in Hindi or Hinglish, the AI shows an English version to check and post. It does not count against the daily limit until posted.
  • Search engines are kept out. The pages are marked so student content never appears on Google.

System architecture

Most of the forum runs on what the School app already has. The video side needs three new parts: a job queue, a worker that can run for several minutes, and outside services for video and voice.

Checks every post goes through

These run on the server, in this order, before a post or reply is visible to anyone. The app's screens show the same rules, but the server is what enforces them.

  1. LoginNo valid token, no access.
  2. ClassTaken from the student's account. Any class sent in the request is ignored.
  3. Parent approvalMust be approved for the class feed. Ask works without it.
  4. Daily limitChecked and counted in one database step, so two posts sent at the same moment cannot both pass. Posts only, not replies.
  5. English checkIf the text is not English, the student gets an English version to confirm.
  6. Pattern checkBlocks phone numbers, email addresses, links and social media handles.
  7. AI moderationGemini checks for abuse, bullying and personal details. Unclear cases are held for an admin.
  8. Saved and liveA post blocked at any step does not use up the daily limit.

Parent approval

  1. DisclaimerThe first time a student opens the class feed, a short notice explains what Doubts is and that a parent must approve.
  2. Parent detailsThe student enters the parent's name and the parent's email or phone number.
  3. Code to the parentThe parent receives a one-time code and a plain summary of what they are approving.
  4. Approval recordedThe app stores the parent's name, contact, time and the version of the terms.
  5. SettingsA Parent approval section shows the status. The parent can withdraw at any time, which locks the class feed again.

A typed parent name on its own is not enough, because a child can type anything. The code sent to the parent is what makes the approval checkable. India's data protection law asks for verifiable parental consent for children, so a lawyer should confirm the wording before launch.

Video generation

A video is one minute long: 5 scenes of 12 seconds. Each scene is stored on its own with a text description, so a later video can fetch a scene that fits and generate only the rest.

Three rules that make reuse possible

  • Scenes are stored silent, with no text in the picture. Narration differs for every video, so a clip with a voice or words baked in cannot be reused.
  • One house style. Every scene shares the same art style, recurring characters, size, frame rate and length. Each scene carries a style version, and scenes are only matched within the same version.
  • Every scene stands alone. No action carries over from one scene to the next, so any scene can sit beside any other.

How one video is built

  1. Whole-video checkIf the same topic was already made for the same class band, that video is reused and nothing is generated.
  2. ScriptGemini writes 5 scenes. Each has narration of about 25 words, a description of what is seen, and a scene type.
  3. Library search, per sceneThe description is compared by meaning with stored scenes of the same style, class band and type. A second Gemini check confirms the clip really fits this script.
  4. Fill the gapsScenes with no match are generated by the video model, or drawn by code for exact content like maths steps.
  5. Quality checkGemini looks at frames from each new clip: does it match the description, is it child-safe, is there garbled text? A failed clip is retried once, then replaced with a code-drawn scene.
  6. VoiceEach scene's narration is turned into English audio with one fixed narrator voice. If the audio runs over 12 seconds, the line is shortened and redone.
  7. AssemblyThe worker joins the 5 clips, lays the audio over them and adds a separate captions file. The result goes to Cloudinary.
  8. Store and attachNew scenes enter the library. The video is attached to the doubt. If the job fails, the student's video allowance is not used.

Scene types

TypeExampleMade byReuse
GenericA student walking to school, a classroom, a teacher at the boardVideo modelHigh, across subjects
ConceptAn ice cube floating in a glass of waterVideo modelOnly for the same concept

Class bands for matching are 1–3, 4–5, 6–8 and 9–10, so a scene made for young children is not placed in a Class 10 video.

The parts and how each is possible

PartHow it is built
Script writerGemini, already in the app, asked to return the 5 scenes in a fixed structure. videoLectureService.js already writes scripts this way.
Scene searchEach description is stored with a list of numbers that captures its meaning, produced by Gemini's embedding model. Search finds the closest ones. MongoDB Atlas has this search built in. If the database is not on Atlas, the comparison runs in code while the library is small.
Clip generatorA video model called over its API with the house-style instructions and reference pictures of the recurring characters. Google's Veo is the first candidate because the app already uses Gemini.
Code-drawn scenesAnimated slides produced by a program, using a tool such as Remotion or Manim. Text and numbers are always exact, and the cost per scene is close to zero.
VoiceA text-to-speech service with one fixed English voice.
Assemblyffmpeg, a standard free tool for joining video and audio.
WorkerA background job runner that can work for several minutes. A normal web request on Vercel ends long before a video is ready. Options are Vercel's long-running workflows or one small separate server.
Progress screenAlready exists. The app polls the job status and shows progress.

What to expect

  • Scene reuse starts low. The library begins empty. Early savings come from the whole-video check. Scene reuse grows as the library fills, mostly for Generic scenes.
  • Clip length depends on the model. Some video models cap a single clip at about 8 seconds. The week 1–2 test must confirm 12-second clips are possible. If not, the scene length changes to fit the model, and the rest of the design stays the same.
  • Keeping a character identical across clips is hard for today's models. Reference pictures help. Scenes that show objects, hands and settings reuse more safely than scenes built around one face.
  • AI video is poor at exact diagrams and text. That is why Specific scenes are drawn by code and why no scene has text in the picture.
  • A video takes minutes. The student sees progress and can leave the page. The video appears in Mine when ready.

Keeping cost under control

Cost of one video = new scenes × clip length × the model's price per second, plus voice and a small amount of Gemini text. Reused scenes and reused videos cost nothing to generate.

  • Whole-video reuse first, then scene reuse.
  • Video generation for paid users only, with a monthly allowance per user.
  • A daily spending cap for the whole app, with a switch that pauses generation when it is reached.
  • Watching an existing video is free for everyone in the class.

Risks

RiskHow the plan handles it
A child-safety incidentEvery post is checked before it is visible. No private messages. Limited names. Parent approval. Report button and admin queue. None of these are optional for launch.
An empty feed at launchStarter doubts per subject. Answer using AI means no doubt stays unanswered. Neighbouring classes can be combined if a class is quiet.
Video cost runs awayPaid only, monthly allowance, daily spending cap, and reuse at two levels.
Reused scenes look out of placeHouse style with version tags, standalone scenes, and a fit check before any scene is reused.
A video teaches something wrongExact content is drawn by code. Thumbs-down lowers a scene's rank. Admins can remove a scene and see which videos used it.
Students get around the daily limitCounts are stored in MongoDB and checked in one step. Deleting a post does not give the post back.
English-only pushes students awayThe AI offers an English version instead of rejecting the post.
The video model cannot do what is neededTested in weeks 1–2, before any pipeline work depends on it. The forum track does not depend on video at all.
